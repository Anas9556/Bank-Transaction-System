Frequently Asked Questions

Institutional operational clarity on common ledger actions, consensus checkpoints, and protocol behaviors.

Navigate to Transactions → Add Transaction (+). Select the transaction classification (Income credit or Expense debit), input the gross amount in INR, designate the settled target account, and select the GAAP classification category. The double-entry engine computes the balance trajectory, validates pre-flight node invariants, and anchors the posting with cryptographic consensus.

METADATA: TAGS: TRANSACTIONS, DOUBLE-ENTRY, GAAP | CONSENSUS LATENCY: ~12ms

Income increases ledger equity via an external counterparty credit, while Expense decreases capital reserves via an authorized disbursement. In contrast, an internal Transfer is a dual-leg atomic movement between two internal accounts (e.g., Primary Operational to Savings Reserve Vault) which results in a net-zero capital delta (₹0.00) on overall treasury equity.

POSTING RULE: DEBIT DESTINATION (+), CREDIT SOURCE (-) SIMULTANEOUSLY

In the Transactions ledger explorer or Reports & Analytics, toggle the temporal period selector (7D, 30D, 90D, YTD, or Custom ISO date range). You can filter the ledger view by target account, classification, or execution node to isolate specific journal entries with sub-millisecond query indexing.

Ledgerly enforces strict bi-temporal accounting. Discrepancies usually stem from unsettled pending verification transactions, uncommitted Raft batch logs, or difference between Settled Balance and Available Balance due to active treasury policy buffer floors or collateral locks.

Open any settled transaction record and inspect the 'Ledger Record & Cryptographic Proof' panel. Each entry displays its block height, Merkle root leaf, previous block hash, and current digest. You can click 'Verify Cryptographic Proof' to validate that the record has not been altered or backdated against peer nodes.
